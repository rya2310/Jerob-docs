# Jerob Website

A modern landing page built with React, TypeScript, Vite, and Tailwind CSS.

## Features

- React 19 + TypeScript
- Vite-powered development and production builds
- Tailwind CSS styling with PostCSS
- Motion animations via Framer Motion
- Icon support through lucide-react
- ESLint for code quality

## Project structure

- `src/main.tsx` — application entry point
- `src/App.tsx` — main app shell
- `src/index.css` — global styles
- `src/components/` — reusable UI sections and feature components
- `public/` — static assets served by Vite

## Getting started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

Lint the project:

```bash
npm run lint
```
